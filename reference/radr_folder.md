# radr_folder

Generate the rad folders

## Usage

``` r
radr_folder(rad.folder, path.folder = NULL, prefix.int = TRUE)
```

## Arguments

- path.folder:

  path of the folder

- prefix.int:

  Use an integer prefix padded left with 0. Default:
  `prefix.int = TRUE`.
