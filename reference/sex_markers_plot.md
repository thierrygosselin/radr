# sex_markers_plot

Function to generate the different figures required for 'sexy_markers'.

## Usage

``` r
sex_markers_plot(
  data,
  x,
  y,
  x.title = "x title",
  y.title = "y title",
  subtitle = "subtitle",
  title = "Big title",
  width = 15,
  height = 15,
  scat = FALSE,
  tuckey = FALSE,
  qreg = FALSE,
  hist = FALSE,
  RD = FALSE,
  plot.filename = NULL,
  path = NULL
)
```
