# Figure of the distribution of SNP nucleotide position alond the read

Distribution of SNP nucleotide position alond the read.

## Usage

``` r
plot_snp_position_read(data, aes.colour, y.title)
```

## Arguments

- data:

  Data for the figure.

- aes.colour:

  GGPLOT2 aesthetic.

- y.title:

  Title of the Y-axis.
